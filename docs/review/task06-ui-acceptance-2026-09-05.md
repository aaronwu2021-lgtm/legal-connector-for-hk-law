# 页面与交互验收（2026-09-05）

本轮调整集中在 `server/public/index.html`。保留既有双语视觉与诉讼用途入口；本记录只说明已执行的检查，不代表全站无障碍认证或法律内容正确。

## 已接受的行为

- 四法域来源卡片默认收起，桌面两列，窄屏一列。首页数字入口改为原生按钮，支持键盘操作；诉因与检索筛选有可读名称。
- 条文、补充判例、要件权威及评分权威就近展示原记录的 pin、source/src。缺少必需字段时明确提示；没有把相同判例另一条记录的来源或等级复制过来。
- 核验结果区分本地名称/引证匹配与 HKLII 中立引证检索。可用性未知不当成判例不存在，匹配也不当成命题核实。
- 每次导航拥有独立页面容器。延迟成功或失败只能影响原页面，不再覆盖后来打开的页面。检索还检查请求次序和当前查询条件；加载、无结果和失败分别显示。
- 判例详情支持加载状态、无结果和请求失败提示。API 示例为要件使用实际的 E3c ID，重复点击复用同一个输出区域；失败可以重试。
- 图谱离开页面后停止动画并注销拖动结束监听，避免导航后继续占用资源。
