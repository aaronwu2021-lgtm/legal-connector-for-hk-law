## Reproduced defects

- Empty HKJUR facts produce a zero-width net interval and `interval_decides:true`, despite all facts being unknown. Unknown negative factors do not appear in the next-evidence queue.
- Negative stored counter-factor bounds become inverted when absolute values are taken separately: e.g. [-0.30,-0.20] must contribute a signed interval [-0.30,-0.20], not reversed bounds.
- A conjunctive CONTRACT stage enters the balancing branch and is described as waiting for calibrated weights.
- Unknown clause presence is treated as false; a known clause with unknown override is treated as definitely enforced.
- Module aggregation takes the first balancing stage and can ignore unresolved prerequisites, conditional alternative routes and other stages. The data does not encode a complete stage-dependency graph.

## Decisions and acceptance requirements

1. Validate `facts` as an object (not null/array/scalar when explicitly supplied). Normalize the currently supported true values (true, 1, "true", "yes"), false values (false, 0, "false", "no"), and unknown values (missing, null, "unknown", "?") into three states. Reject other supplied values explicitly; they must not silently become false. Unknown factor IDs must be reported/rejected so misspellings cannot masquerade as evidence. Preserve omitted facts as an empty record. Return actionable REST/MCP errors for invalid inputs.
2. Balancing intervals include both uncertainty sources: assigned weight bands and unknown fact presence. A known-true pro factor contributes [low,high]; known-false [0,0]; unknown [0,high]. A counter factor contributes [-high,-low] if true, [0,0] if false, [-high,0] if unknown. Derive sorted magnitudes from either negative or positive counter bounds; assert low<=high in all outputs. Do not change data bands.
3. With no resolved facts, return `result:"undetermined"` or equivalent, `interval_decides:false`, and an explicit insufficient-evidence explanation. A numerical interval may be shown as a scenario range, not a legal outcome. With partial evidence, any claim that a heuristic band is stable must include all unknown contributions. Never label it a probability of success.
4. If any balancing factor lacks a usable finite weight/range, do not silently treat its contribution as zero or compute a partial definitive score. Return a nonnumeric checklist and `weights:"incomplete"`/`"unassigned"`, distinguishing missing assigned bands from the absence of empirical calibration. Do not say a doctrinal band is empirically calibrated.
5. Queue unresolved factors from both pro and counter sides. Include a direction field and rank by maximum unresolved swing magnitude. Distinguish weight uncertainty, fact uncertainty, and missing model semantics in explanations. Evidence coverage must be zero when all applicable facts are unknown, remain within [0,1], and must not count invalid values as resolved.
6. Every test type needs an explicit branch. Conjunctive tests must return present/absent/unresolved factor checklists and no numeric score or calibration wording. Since the current data lacks required/optional labels and some stages have exceptions (LS-1 says rent is not absolutely necessary), do not assume every listed factor is a legally mandatory element. Use a clear manual/checklist status if the encoded semantics are insufficient. Presumption–rebuttal without explicitly identified trigger/rebuttal roles must similarly remain manual, never balancing. Unknown test types must return unsupported/manual, never fall through into arithmetic.
7. For HKJUR-4, gate unknown => engaged:null and undetermined; gate false => not-engaged; gate true with override unknown => undetermined (not clause-enforced); gate true with override true/false may use the already encoded override logic. Stages with no explicit gate/override remain nonnumeric/manual. Do not invent threshold logic for them.
8. Do not infer a dependency graph or a module-wide legal conclusion. Multistage modules with unencoded stage dependencies must return overall undetermined/manual, explain the missing dependency semantics, and preserve useful per-stage outputs and priority evidence. Do not pick the first balance, require all alternative routes, or translate an enforcement-defence gateway into enforcement success. Existing OR factor results may be shown as checklist-level logical results, but must be expressly distinguished from a legal determination; RT-1 and VL-1 have mixed roles in their rule text, so generic OR must not be advertised as a resolved legal threshold. Do not parse rule prose with regex to invent legal meaning.
9. Adapt the scoring result renderer for all nonnumeric/manual/unsupported/error states. Never produce NaN, null arithmetic, inverted bars or a green legal-conclusion badge for insufficient facts. Preserve the user's current navigation and factor controls. Show Chinese user-facing explanations for insufficient evidence and manual judgment; stable heuristic bands must be labelled as heuristic, not court outcomes.

Verify the full uncertainty range contains all endpoint combinations for a selected finite subset of real factor fixtures (an independent interval check, not simply reproducing the implementation formula). No network or data writes.
