# 法律标准本身怎样计算化

这里讨论的是：**什么预防属于合理、什么程序足够公平、什么限制过度、什么减损措施应当采取**。这些是规范判断。日志复算、金额核算可以提供输入，但不会自行回答“法律要求应当怎样做”。

计算化有三个层次：法院明确提出的数学表达；法规或判例中的比较结构；本项目为分析该结构建立的辅助模型。必须标明属于哪一层，不能把自行设定的参数包装成法律阈值。以下数字全部为合成教学假设，金额统一称“元”，不涉及真实案件。

## 七项标准及其地位

| 模型 | 法律问题 | 来源法域、场景 | 数学表达的地位 |
|---|---|---|---|
| `hand` | 理性行为人是否应采取某项预防？ | 美国海事过失案件 *Carroll Towing* | 原判明确写出成本与预期损失比较；本项目扩展为措施实际减少的风险 |
| `alarp` | 是否已将风险降至合理可行的最低程度？ | 英国职业健康及安全监管 | “严重不成比例”是真实标准；成本收益比只是辅助，没有通用法定倍数 |
| `interim_injunction` | 临时禁令两种错误中哪种造成的损害较大？ | 美国第七巡回法院 *American Hospital Supply* | 原判提出概率乘损害的启发式，并明确不是新的法律标准 |
| `procedural_safeguards` | 是否需要增加听证、复核等程序保障？ | 美国程序正当性，*Mathews* | 三因素来自原判；下述净收益公式是本项目形式化 |
| `necessity` | 是否存在足够有效而侵害更小的手段？ | 英国公法及权利限制，*Bank Mellat* | 分阶段结构来自原判；替代方案筛选是形式化，不能代替完整比例审查 |
| `reasonable_mitigation` | 受损方应否采取某项合理减损措施？ | 英国违约损害赔偿 | 合理减损是规范；预期收益比较是辅助，不是事后最优化义务 |
| `penalty_proportionality` | 违约后负担是否与合法履约利益严重不成比例？ | 英国合同罚则，*Cavendish* | 次级义务及比例审查来自原判；金额比值不是裁判阈值 |

这些来源不自动成为香港法。原判被阅读、程序被执行和某规则适用于指定案件，是三个不同判断。模型输入及接口以 [模型目录](../legal_quant/models.json)、[计算规范](../legal_quant/SCHEMA.md) 为准。

## 1. 合理注意：`hand`

原式是 \(B<PL\)：比较预防负担与损害概率乘损害大小，**不是把损害再乘预防成本**。这是一种理解预防是否值得采取的司法表达，并非完整过失责任公式。[Carroll Towing, 159 F.2d 169, 173–174](https://law.justia.com/cases/federal/appellate-courts/F2/159/169/1565896/)

措施只能减少部分风险时，本项目比较：

\[
\Delta EL=NpL\,[1-(1-e_p)(1-e_L)],\qquad NB=\Delta EL-B.
\]

| 符号 | 单位及依据 |
|---|---|
| \(N\) | 同期间暴露次数；来自操作记录和明确的统计口径 |
| \(p\) | 每次事故概率，0–1；来自适用样本或有依据的风险估计 |
| \(L\) | 每次事故的条件平均损失，元；保留损失类别和估值依据 |
| \(e_p,e_L\) | 概率、严重程度的减少比例，0–1；来自试验或经说明的假设 |
| \(B\) | 同期间预防负担，元；包含实施、维护及可合理估值的副作用 |

假设 \(N=1,p=0.02,L=100000,e_p=0.75,e_L=0,B=1000\)，预期减少损失1,500元，净收益500元。输出支持“该措施在这些假设下经济上有利”；义务范围、可预见性、实际可行性、因果及可赔损失仍须分别认定。

来源校对：上述 Justia 转载的英文为“less than”，紧接的比较符号却显示相反方向；[已核教学节选](https://sites.oxy.edu/whitney/xaccess/ec357/cases/tort/unitedstates_v_carrolltowing.htm)为 \(B<PL\)。不沿用转载符号错误；增量式不是原判原文。

## 2. 合理可行：`alarp`

ALARP 的问题不是“成本稍高于收益就可以不做”，而是进一步预防的负担是否与风险减少**严重不成比例**。HSE 的解释包括金钱、时间及努力。[HSG175, ¶26](https://www.hse.gov.uk/pubns/priced/hsg175.pdf)

辅助量为 \(R=C/\Delta EL\)。\(C\) 是同期间措施成本，\(\Delta EL\) 是同期间风险减少的货币估计，均为元；来源分别是实施报价、风险分析和明确的伤害估值依据。比值无单位，收益为零时不能直接作除法。

例如成本30,000元、估计风险收益10,000元，\(R=3\)。**只能说成本为估计收益三倍，不能据此说已经满足 ALARP。**可容忍性、相关良好实践、估计不确定性及“严重”的判断仍在计算之外。ONR 明确区分法律上的严重不成比例与并非法定的数值范围。[ONR 监管回应，第379项](https://www.onr.org.uk/media/documents/saps/commments-and-responses.pdf)

## 3. 临时禁令：`interim_injunction`

司法启发式为：

\[
pH_p>(1-p)H_d.
\]

\(p\) 是申请人最终胜诉的情景概率，0–1；\(H_p\) 是错误拒绝禁令给申请人造成的不可弥补损害，\(H_d\) 是错误准许给被申请人造成的损害。两种损害须使用有说明的共同单位和相同期间；诉讼及影响证据支持估计，AI 自报信心不是 \(p\)。

假设 \(p=0.4,H_p=100000,H_d=30000\)，两侧是40,000与18,000。这组假设偏向准许，但不能跳过不可弥补损害、法律救济充分性、实体胜诉要求及公共利益。原判明确说公式是既有因素的摘要，**不是新的法律标准**；也不能将1986年该巡回法院的表达当作今日所有法域的完整禁令测试。[American Hospital Supply, 780 F.2d 589, 593–594](https://law.justia.com/cases/federal/appellate-courts/F2/780/589/148335/)

## 4. 程序保障：`procedural_safeguards`

*Mathews* 要求考虑个人利益、现有程序造成错误剥夺的风险及额外保障的价值、政府职能及程序负担。判词没有给出一个净收益不等式。[Mathews v Eldridge, 424 U.S. 319, 335](https://www.law.cornell.edu/supremecourt/text/424/319)

本项目仅对可估计部分作 \(\Delta E=(q_0-q_1)V-C\)：\(q_0,q_1\) 为增设保障前后的错误概率；\(V\) 为一次错误剥夺的损失估值；\(C\) 为每案新增程序成本，后二者单位为元。错误率应有复核样本或试验依据，估值及行政工时须说明来源。

例如错误率从8%降至2%，可估计损失20,000元，复核成本300元，净减少900元。结果支持进一步考虑复核，却不能把尊严、参与权、生命自由或最低程序保障折价卖掉；净值为负也不自动证明程序充分。

## 5. 必要性与比例原则：`necessity`

依次审查目的、合理联系、较少侵害的可行替代、最终利益与权利负担的平衡。可计算的一个子问题是：

\[
\exists a:\quad E(a)\ge E(m),\quad H(a)<H(m),\quad F(a)=\text{可行}.
\]

\(m\) 为现方案、\(a\) 为替代；\(E\) 是同一目标的效果指标，\(H\) 是某项具体侵害指标，\(F\) 是有工程、财政或制度依据的可行性判断。效果及侵害分别保持自己的单位，**不相加成权利总分**。

例如两个方案均预计每年避免100次错误披露，一个保存数据365天，另一个30天且可行。后者构成较少侵害的候选；仍须检查其他隐私风险、效果证据及遗漏的替代。没有找到候选不证明必要；法院也不是机械要求唯一最小侵害方案。[Bank Mellat (No 2), [2013] UKSC39, ¶20、¶¶74–75](https://supremecourt.uk/uploads/uksc_2011_0040_judgment_32e27b53c6.pdf)

香港 *Hysan* 的四阶段背景可参阅[律政司案例汇编](https://www.doj.gov.hk/en/publications/pdf/Basic_Law_Selected_Drafting_Materials_and_Significant_Cases_Vol_2_en.pdf)；这里将其标为官方二手说明，本次未据此声称已核原判或完成香港适用性审查。

## 6. 合理减损：`reasonable_mitigation`

对某措施可比较 \(NB=pA-C\)：\(p\) 是成功概率，\(A\) 是成功时避免的损失，\(C\) 是采取措施成本；金额同币种同期间，概率及可行性依据须来自**当时**可得的信息。若措施还可能引入额外损害，应另计，不能藏在输入之外。

例如成功率60%、可避免50,000元损失、成本8,000元，净收益22,000元。这是经济支持，未采取不自动违反减损规则。法律不要求受损方事后挑中最佳方案；合理措施即使失败、增加损失，其费用仍可能获赔，成功避免的损失则应扣除。[Sharp v Viterra, [2024] UKSC14, ¶¶83–87](https://supremecourt.uk/cases/judgments/uksc-2023-0029)

## 7. 罚则比例：`penalty_proportionality`

先判断违约触发的负担是否属于次级义务，再审查其是否与合法履约利益严重不成比例。不能将“约定金额超过实际损失”直接视为罚则。[Cavendish / ParkingEye, [2015] UKSC67, ¶32、¶255](https://supremecourt.uk/uploads/uksc_2013_0280_judgment_c7f37dda32.pdf)

可辅助显示 \(R=D/L_c\)：\(D\) 是约定负担的货币值，\(L_c\) 是订约时预计补偿性损失的情景估计，均为元；前者来自条款，后者来自订约资料及有依据的情景分析。零分母不能被强行转成有效比值。

例如约定100,000元、预计补偿性损失20,000元，比值为5。它提示应解释负担，但**5倍不是法定无效阈值**。商誉、服务管理等合法利益可能不等于损害赔偿额；也不能自行给这些利益打分后宣布条款有效。

## 怎样在项目中使用

先确定法域、时间及规范，再列适用门槛，最后计算允许量化的部分。每个输入保存“证据／估计／假设”、来源、单位、估值日及不确定范围；未知不是零。输出应呈现条件结果、争议参数和仍待作出的法律判断，而非合成一个责任分数。

Bayes 回答事实命题怎样被证据更新；Coase 比较资源配置；损失、现值模型计算条件金额。它们可供上述标准使用，但本身不是合理注意、程序公平或比例原则的裁判标准。既有 `alexy` 也属于理论权衡工具，其等级不是法院规定的权利价格。更多辅助模型见[量化模型文档](legal-quantitative-models.md)。

Python 可直接使用目录中的教学参数，再逐项替换为有依据的输入：

```python
from legal_quant import evaluate, get_model

model = get_model("interim_injunction")
result = evaluate(model["id"], model["example_inputs"])
print(result)
```

本文公式解释规范结构，不承诺每个符号就是接口字段。实际参数以目录为准；示例输出不是法律结论。
