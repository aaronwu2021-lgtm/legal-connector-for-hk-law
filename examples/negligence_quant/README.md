# Python 过失责任量化工作表

这是一个可以替换输入并重复运行的**教学与研究模型**。它逐项计算事实指标、措施成本、风险减少额、损失和扣减情景；法律要件的认定保留为独立输入。示例全部是假设数据，不是香港真实事故数据、判赔标准或经校准的司法预测。

这是完整过失分析的独立 Python 工作流；项目的[量化模型库](../../docs/legal-quantitative-models.md)另将固定输入的汉德计算与其余十种模型接入网页和 REST/MCP。此处的多方案、不确定性和法律节点记录通过 Python 运行。只需 Python 3.10+，不需要安装第三方包。

## 运行与文件

在仓库根目录运行：

```powershell
python examples/negligence_quant/assessment.py --draws 10000 --seed 42
python -m unittest discover -s examples/negligence_quant -p "test_*.py"
```

也可指定自己的输入和输出位置：

```powershell
python examples/negligence_quant/assessment.py --input path/to/case.json --out path/to/results
```

- `example_case.json`：完整输入；修改这里的金额、概率范围、措施、证据和外部法律认定。
- `assessment.py`：法律问题记录、事实指标、观察事故率、群体比较、个案损失、方案增量比较与输出。
- `risk_engine.py`：年化成本、预期损失、临界值、边界分析及参数模拟。
- `results/assessment.json`：完整结果，含未决问题和数据限制。
- `results/measures.csv`：各措施的计算结果，可在 Excel 中查看。

## 1. 整个过失责任怎样拆分

以下是本工具声明的一条分析路径，不是所有法域、所有过失案件的通用法定清单。专业过失、纯经济损失、不作为、法定责任等需要各自的法律审查。

| 模块 | 需要回答的问题 | 可量化的事实或经济指标 | 不能由数字直接替代的判断 |
|---|---|---|---|
| 注意义务 duty | 谁对谁、就哪一种危险负义务？ | 管理面积/总面积；控制时段；接触次数；风险通知次数、日期 | 法律关系、承担责任、适用义务及其范围 |
| 违反义务 breach | 事故前本应采取什么措施？ | 概率、暴露量、损失、成本、措施效力、巡检完成率、响应时间 | 适用注意标准、成文要求、可预见性和具体情境 |
| 事实因果 factual causation | 若履行义务，本次损害是否仍发生？ | 事件顺序、剂量、时间与距离、比较组事故率、工程测试 | 具体个案反事实、因果规则及证明是否充分 |
| 责任范围与过远性 | 这种损失是否在本案责任范围内？ | 损失项目金额、时间、地点、风险机制分类 | 义务保护的风险、损害类型、介入原因与法律过远性 |
| 可赔损害 damage | 存在什么经证明、可获赔的损失？ | 医疗、工资、护理、未来现金流现值、已给出的非财产损害估值 | 项目是否可赔、证据是否成立、适用估值规则 |
| 抗辩与时效 | 有哪些可能阻却请求的因素？ | 日期差、行为时间、同意范围内的可观察事实 | 抗辩成立、举证责任、时效起算/暂停/延展 |
| 赔偿调整 | 是否扣减，按什么顺序及比例？ | 已确定的可避免损失金额、外部给出的共分疏忽比例 | 扣减的适用性、公正分摊及调整顺序 |

每个法律节点保存 `proposition`、`finding`、`basis`、`evidence_ids`、可量化事实和解释边界。状态为 `supported / not_supported / unknown`，可选问题另允许 `not_applicable`。这里“supported”仅指**外部输入声称已支持**，并非程序验证了证据。

不采用“义务20分＋违反义务30分＋因果关系30分”的总分。任一未决节点会被列出；一个节点不获支持，也不会被其他节点的高数字抵消。程序不生成“胜诉率”或“法院认定过失概率”。

## 2. B：把预防负担拆成可核对的成本

令初始投资为 K、使用年限为 T、年折现率为 r：

```text
年化资本成本 = K × r / [1 - (1+r)^(-T)]      r > 0
年化资本成本 = K / T                         r = 0
B = 年化资本成本 + 年维护 + 年人工 + 年培训
    + 年机会成本 + 年使用者时间成本 + 其他不重复的年成本
```

每个项目应另有数量依据：

| 成本项 | 可使用的计算方式 | 证据 |
|---|---|---|
| 人工 | 次/年 × 小时/次 × 全成本时薪 | 排班、工时、工资记录 |
| 培训 | 人数 × 小时/人 × 时薪 + 培训采购费 | 培训计划、报价 |
| 维护 | 次/年 × 单次维护费 | 合同、维修记录 |
| 使用者时间 | 受影响人次 × 分钟/人次 ÷ 60 × 每小时估值 | 流量与时间测量、明确的估值来源 |
| 停业或停用 | 可归因的净机会损失，扣除节省成本 | 经营及替代方案数据 |
| 社会功能损失 | 可估计部分另列，无法估值的保留未量化 | 服务容量、替代服务可得性 |

示例防滑方案：300,000 / 5 + 20,000维护 + 30,000人工 + 10,000绕行时间 = **120,000港元/年**。示例 r=0 是演示设定，不是推荐折现率。

统一币种、价格年度和视角。本工具采用“已货币化的资源及损害成本”视角；私人赔款、保险支付、保费和社会损失不能无区别相加。营收减少也不自动等于净社会损失。无法货币化的权利和服务影响不能填0。

资本年化假设年成本与风险可比较、寿命期内近似稳定。对短期项目、残值、变动暴露量、通胀或不同现金流路径，应改用同一期间的贴现现值。

## 3. P：先写清分母

本工具使用**每次暴露发生一次事故的概率**：

```text
p = 事故次数 / 同类暴露次数
N = 每年暴露次数
每年预期事故次数 = N × p
```

一次暴露在示例中是“一人在指定区域的一次通行”。100,000次通行发生8次事故，得到 p=0.00008，即 **0.008%/次**，或每10万次暴露8次事故。

`N × p = 8` 是每年预期事故**次数**，不是800%概率，也不是“全年至少一次事故”的概率。后者在独立同概率假设下为 `1-(1-p)^N`，不是本工具用来乘单次损失的量。

观察数据使用 Wilson 95%区间：本例约为每10万次暴露 **4.05–15.79次**。它假设暴露可比、近似独立、每次暴露只有一个二元事故结果；聚类、重复伤害、漏报或工况变化时需要改模型。零事故样本仍有正的区间上界。

风险引擎另用 `low=0.00003, mode=0.00008, high=0.00018` 的三角分布作参数情景。这是人为声明的范围，**不是上述置信区间或自动生成的贝叶斯后验**。

按易感人群、白天/夜间、雨天/晴天等分层时，使用 `Σ N_g × p_g × L_g`，不要让平均值掩盖高风险群体。目前示例只有一个暴露群体，分层扩展尚未实现。

## 4. L：用损失分布，不只用“最严重情况”

损失类别必须互斥、覆盖当前建模事件；`q_s` 是**已发生事故条件下**属于该严重度类别的比例：

```text
L = Σ q_s × L_s
L_s = 医疗 + 收入损失 + 护理/康复 + 其他不重复损失
```

示例：

| 事故严重度 | 事故后的条件占比 | 单次损失代表值 | 对条件平均损失的贡献 |
|---|---:|---:|---:|
| 轻伤 | 80% | 10,000 | 8,000 |
| 中度伤害 | 18% | 200,000 | 36,000 |
| 严重伤害 | 2% | 3,000,000 | 60,000 |
| 合计 | 100% | — | **104,000** |

严重伤害只占2%的事故，但贡献约57.7%的预期损失。三百万元只是损失情景，不是生命的定价或法院赔偿上限。未货币化的严重后果仍需要单列。

不要将各类别概率既计入 p 又重复计入 q；不要把已经折现的损失再次折现。类别占比在当前模拟中固定，尚未估计其抽样不确定性。

## 5. 比较“减少了多少风险”，而不是全部基线风险

令 e_p 为事故概率降低比例，e_L 为事故后条件损失降低比例：

```text
EL0 = N × p × L
EL1 = N × p × (1-e_p) × L × (1-e_L)
减少的预期损失 = EL0 - EL1
净收益 NB = EL0 - EL1 - B
措施后的总货币化成本 = B + EL1
```

经济上支持某一措施的条件是 `B < EL0-EL1`。只有该措施消除了被比较的全部风险时，减少额才等于完整基线损失。最优方案是**所声明的可比较完整方案中**总货币化成本最低者；也纳入不新增措施的基线。

默认各参数取 mode 得到：

| 完整方案 | 年成本 B | 概率降低 | 年残余损失 | 年净收益 | 年总货币化成本 |
|---|---:|---:|---:|---:|---:|
| 不新增措施 | 0 | 0% | 832,000 | 0 | 832,000 |
| A 警示与提醒 | 12,000 | 10% | 748,800 | 71,200 | 760,800 |
| B 防滑设施与巡检 | 120,000 | 60% | 332,800 | 379,200 | 452,800 |
| C 防滑设施与驻点人员 | 260,000 | 80% | 166,400 | 405,600 | 426,400 |
| D 全年关闭该区域 | 1,200,000 | 100% | 0 | -368,000 | 1,200,000 |

全部单位为港元/年。C的总成本最低，但相较B只再减少166,400损失，同时多花140,000，**增量净收益仅26,400**。

这些是互斥的完整方案，不能把B、C成本或效力相加。组合措施应作为另一个完整方案录入，并估计其联合效果。实际措施可能带来新风险、降低某些风险却增加其他风险；当前只有减小同类风险的参数，需另建事件树才能覆盖这些情况。

## 6. 临界值让结论可以被质疑、被更新

固定其他参数时：

```text
p* = B / {N × L × [1-(1-e_p)(1-e_L)]}
```

以防滑方案B为例，p*约为每10万次暴露 **1.923次事故**。若真实概率低于它，该方案在此组金额和效力假设下没有正净收益。

若 e_L=0，最低所需概率降低比例为：

```text
e_p* = B / (N × p × L)
```

方案B为 **14.42%**。方案D为 **144.23%**，超过100%，表明在当前基线下即使彻底消除这一类风险，也不足以抵销关闭成本。程序保留大于1的结果，不偷偷截断。

进一步比较C与B：若B效果保持60%，C需达到约 **76.83%** 才抵销增加的140,000成本。默认80%距临界点仅3.17个百分点，这比“C得分最高”更能说明需要补什么证据。

## 7. 因果关系：计算事实关联，不伪造个案原因概率

示例另给出一组观察数据：无措施区域8/100,000，有措施区域3/100,000：

```text
观察风险比 RR = (3/100000) / (8/100000) = 0.375
观察相对减少 = 1 - RR = 62.5%
观察风险差 = 0.00008 - 0.00003 = 0.00005/次
```

这些是描述性关联。人群、天气、地面、管理方式及选择机制可能不同；样本也很小。观察的62.5%不自动写入措施的60%预测假设，更不等于“这位原告有62.5%的概率是被告造成”。

个案应另存：已证实的危险出现时间、跌倒机制、位置、医学联系、替代解释、措施是否可在事故前生效、专家的反事实意见。若有随机试验或可信准实验，才能进一步讨论因果效应识别；本示例未实现因果识别模型。

## 8. 个案赔偿另算，不用事故前的平均L代替

示例原告的代表值：医疗60,000 + 已失收入40,000 + 未来护理现值150,000 + 非财产损害情景80,000 = **330,000港元**。

设外部给定可扣减的减损金额为 M、共分疏忽扣减比例为 c，并暂设此顺序适用：

```text
条件赔偿 = max(0, 可赔损失合计 - M) × (1-c)
```

在 M=0、c=20%的纯算术情景下为 **264,000港元**。这里20%不是模型给原告打分得出的，也不是默认香港规则。实际可赔性、扣减适用和顺序需要核验。

支持两种损失输入：

- `present_value`：已经折现到估值日的金额。
- `annual_future_stream`：年末支付的固定年额、年数和明确折现率；程序计算 `Σ annual_amount/(1+r)^t` 的现值。

未来增长、死亡率、就业概率、税务、判后利息、多责任人分摊及法定赔偿上限没有建模。要加入时必须说明适用规则和数据。某项金额或扣减比例缺失时返回 `missing` 和空的条件总额；不按0处理。`legally_payable_amount` 始终为空，因为程序不生成法院裁判。

## 9. 不确定性怎样报告

程序提供三层结果：

1. **代表值情景**：全部参数使用 mode；不是模拟均值或中位数。
2. **输入边界**：取有利/不利角点算净收益范围；不是统计置信区间，也未声称所有极端组合都现实可行。
3. **10,000次参数模拟**：在声明的三角分布内抽样，给净收益5/50/95分位、净收益为正的抽样比例、各方案最优的抽样比例。

默认 `seed=42`：B最优占41.15%，C最优占58.79%；这仅表示在给定分布与相依假设下的排名稳定性，**不是法院选择B/C的概率**。

当前各不确定参数按独立边际抽样，各方案共用同一基线事故率和损失抽样。共享设备或人工成本之间的相依性尚未建模，可能影响排名。严重度占比、暴露量、年限和折现率固定。三角分布是情景假设，不代表已有足够数据验证。

模拟中10,000次全为正，不证明理论概率为100%；经验蒙特卡洛标准误可能显示0，也不意味着没有模型不确定性。示例B的角点范围仍有负净收益，这与其在本次随机抽样中全为正并不矛盾。

## 10. 证据、时间与法律边界

所有数值都应明确：**定义、单位、分母、参考期间、来源、低/代表/高值、是否实测、适用范围和局限**。本例以 `meta`、`evidence`、各输入的 `source`、节点 `basis` 保存这些信息；占位数字不能升级为已核验证据。

`information_available_by` 晚于事故日时，程序拒绝把该批风险输入用于事前违反义务分析。该检查只核对所声明的日期，不验证每份证据实际何时可得。损害评估可以使用事故后的合法证据。

数学可以验证运算，不能验证报价真实、样本可比、因果机制正确或法律适用。义务来源、强制规则、不可货币化价值、完整抗辩与时效不会被一个正净收益结果覆盖。

法律背景来源：

- *United States v Carroll Towing Co.*, 159 F.2d 169, 173–174 (2d Cir 1947)：[Occidental College 保存的原判节选](https://sites.oxy.edu/whitney/xaccess/ec357/cases/tort/unitedstates_v_carrolltowing.htm)。原判提出B<PL并结合时间、地点及值守事实分析，没有给三个变量具体数值；还分别分析不同损失的因果关系。本文的多方案、残余风险及模拟是建模扩展，不是原判逐字规则。
- *Armstead v Royal & Sun Alliance Insurance Co Ltd* [2024] UKSC 6：[英国最高法院原判](https://www.supremecourt.uk/cases/judgments/uksc-2022-0100)，第23段区分责任范围、过远性、介入原因、减损及共分疏忽；第59–60段讨论举证；第73段提醒不要把特定分析框架机械用于所有案件。

以上仅支持分析方式的背景。本轮未完成香港现行法的逐项核验，所以 `jurisdiction_review.finding="unknown"`。这套模型不是全法域法律规则库。
